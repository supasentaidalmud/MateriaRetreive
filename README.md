# MateriaRetreive

MateriaRetreive is a Dalamud plugin that adds a safe review window for retrieving attached materia from inventory and armory gear.

Open it with `/mr` or from an item's context menu. The main window can switch between gearset and non-gearset items, and retrieval only begins after confirmation.

## Custom Repository URL

Add this URL in Dalamud's custom plugin repositories:

```text
https://github.com/supasentaidalmud/MyPlugins/raw/refs/heads/main/repo.json
```
